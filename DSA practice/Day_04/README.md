# Day_04 - DSA Practice Plan

## Pomodoro Schedule (Total: 4 Pomodoros = 2 hours)

### 🍅 Pomodoro 1 (25 min) - Arrays Basics
**Focus: Array Manipulation**

1. **Reverse an Array** (10 min)
   - Write a program to reverse an array
   - Try both: using extra space and in-place reversal

2. **Find Min and Max in Array** (15 min)
   - Find minimum and maximum elements in an array
   - Do it in a single traversal

**✅ Break: 5 minutes** - Stand up, stretch, drink water

---

### 🍅 Pomodoro 2 (25 min) - Array Searching
**Focus: Linear Search & Basic Operations**

1. **Linear Search** (10 min)
   - Implement linear search to find an element
   - Return index if found, -1 if not found

2. **Count Occurrences** (15 min)
   - Count how many times an element appears in array
   - Print frequency of all elements

**✅ Break: 5 minutes** - Walk around, rest your eyes

---

### 🍅 Pomodoro 3 (25 min) - Array Algorithms
**Focus: Two Pointer Technique**

1. **Check if Array is Sorted** (10 min)
   - Write a function to check if array is sorted in ascending order

2. **Remove Duplicates from Sorted Array** (15 min)
   - Remove duplicates from a sorted array in-place
   - Use two-pointer technique

**✅ Break: 5 minutes** - Quick break, hydrate

---

### 🍅 Pomodoro 4 (25 min) - Problem Solving
**Focus: Application & Practice**

1. **Rotate Array** (15 min)
   - Rotate array to the right by k steps
   - Example: [1,2,3,4,5] rotated by 2 → [4,5,1,2,3]

2. **Second Largest Element** (10 min)
   - Find the second largest element in array
   - Handle edge cases (duplicates, small arrays)

**✅ Long Break: 15-30 minutes** - Good job! You've completed Day_04!

---

## 📝 Notes
- Focus on **understanding the logic** rather than just coding
- Test each solution with **multiple test cases**
- Try to optimize: think about **time and space complexity**
- If stuck on a problem for >10 min, sketch the logic on paper first

## ✨ Bonus Challenge (Optional)
If you finish early and feel energetic:
- **Merge Two Sorted Arrays** into one sorted array
- **Find Missing Number** in array [1,2,3,5] → missing: 4
